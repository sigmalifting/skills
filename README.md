# SigmaLifting Skills

This repository contains public agent skills for SigmaLifting.

Current skills:

- `sigmalifting-cli` - Sigma CLI skill for using `sigmalifting-cli`.

Install the CLI first:

```bash
npm install -g https://github.com/sigmalifting/cli.git
sigmalifting-cli doctor --compact
```

Then point your agent at the `sigmalifting-cli` skill folder.
